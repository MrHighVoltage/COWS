Container configuration

Administrator-only typed JSON. Users can select this template but cannot edit or see the resolved values. Mounts use volume by default or COWS-created directory mounts. Directory mounts may set file_manager:true; names are generated from the workspace container name plus optional prefix and suffix. Use named secrets with {{"{{"}}cows.secret.name{{"}}"}}; generated secrets are resolved per workspace.

{{ if .Template.TerminalRootAllowed }}

This template allows terminal access as UID 0 (root) inside the container. That grants full control over the workspace and all writable mounts.

{{ end }}

Example: {"command":["/bin/bash","-l"],"container_user":{"uid":1000,"gid":1000,"name":"{{"{{"}}cows.user.display_name{{"}}"}}","home":"/home/{{"{{"}}cows.user.username{{"}}"}}","shell":"/bin/bash"},"mounts":[{"name":"designs","type":"directory","container_path":"/foss/designs","read_only":false,"file_manager":true,"name_prefix":"workspace-","name_suffix":"-data"}]}

Optional terminal_uids is a list of numeric container UIDs users may select for terminal sessions. For example, "terminal_uids":[1000,0]. UID 0 enables root terminal access.
