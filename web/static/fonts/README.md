# COWS Terminal Font

COWS embeds a small subset of JetBrains Mono Nerd Font Mono from Nerd Fonts
`v3.4.0` for browser terminal rendering and Powerline symbols.

Source archive:

`https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/JetBrainsMono.tar.xz`

The subset retains Latin text, common punctuation, arrows, box drawing, block
elements, and the Powerline range `U+E0A0-U+E0D4`. It is distributed under the
SIL Open Font License 1.1 in `OFL-1.1.txt`.

Files and SHA-256:

To update it, download the exact upstream release, regenerate the same Unicode
subset as documented above, recompute these checksums, and review the license.
